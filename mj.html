Informations techniques

Projet Firebase : alaricstock-c51d1

Taux : 1 PO = 100 PA ; 1 PA = 100 PC ; 1 PO = 10 000 PC.

Objets de base : fichiers JSON statiques de GitHub Pages, communs aux deux groupes. Les objets créés, les stocks et les masquages sont indépendants par groupe dans Firestore.

# Contrôle de migration des prix V6.2 → V7

- 75 supports de base, 536 affixes, 2 278 liaisons et 2 352 fiches RP.
- 2 168 liaisons publiables, dont **2108 prix différents** de V6.2.
- 109 liaisons À préciser et 1 Exclu : non proposées par l’atelier.
- **3** références sur 63 changent de prix catalogue de départ :
  - Potion de soins mineure : 2500 PC → 2250 PC
  - Potion de mana mineure : 3000 PC → 2700 PC
  - Grenade de feu : 6875 PC → 7563 PC

Le fichier CSV des prix de liaisons comprend aussi les lignes inchangées pour faciliter les comparaisons.
Les nouveaux prix sont arrondis au PC pour la vente. Les données détaillées du classeur sont préservées dans le répertoire `documentation/source`.
